# 资源采集与配置指南

> 本文仅供学习与研究使用，提交任何账号或 Cookie 前请确认已获得目标平台允许。不要在生产环境或未经授权的场景下使用这些步骤。

## 1. 账号准备流程

1. **创建独立浏览器配置**
   - 建议为每个平台使用单独的浏览器 Profile（Chrome/Edge）或使用无痕模式。
   - 关闭所有翻译/自动填表插件，避免在抓包时注入额外脚本。

2. **手动登录目标平台**
   - 使用真实账号完成一次完整登录流程，确认可访问首页与搜索功能。
   - 登录后先浏览几条内容，确保平台完成风险校验。

3. **提取 Cookie**
   - 打开浏览器开发者工具 → `Application` / `Storage` → `Cookies`。
   - 根据平台复制关键字段：
     - **小红书**：`a1`、`web_session`、`xsec_token`、`xsec_source`。
     - **微博**：`SUB`、`SUBP`、`SSOLoginState`。
     - **抖音**：`passport_csrf_token`、`sessionid`、`odin_tt`。
     - **快手**：`did`、`kpf`、`kpn`、`client_key`、`kuaishou.api_st`。
     - **哔哩哔哩**：`SESSDATA`、`bili_jct`、`DedeUserID`。
     - **贴吧**：`BDUSS`、`STOKEN`。
     - **知乎**：`z_c0`、`d_c0`。
   - 将复制的键值对按 `key=value;` 拼接成一行，粘贴到“新增账号”弹窗的 `Cookies` 输入框。

4. **添加至资源池**
   - 访问前端页面 **资源管理 → 新增账号**。
   - 选择平台、填写账号标识（如 `xhs_account_01`）并粘贴 Cookie。
   - 保存后可在列表中查看账号状态，配合“启用/停用”按钮管理使用权。

## 2. 代理配置流程（快代理）

1. 在 [快代理控制台](https://www.kuaidaili.com/?ref=ldwkjqipvz6c) 购买私密代理套餐，记下 `secret_id`、`signature`、账户用户名与密码。
2. 进入前端页面 **资源管理 → 新增代理服务商**，按提示填写：
   - 配置名称：便于区分不同套餐，例如“默认快代理”。
   - 快代理凭证：`secret_id`、`signature`、用户名、密码。
   - 池容量：系统希望维持的可用代理数量（默认 10）。
   - 同步间隔：定时刷新代理池的周期，单位分钟。
   - 可用性校验与启用开关：默认保持开启即可。
3. 保存后点击列表中的“刷新”按钮，系统会即时请求快代理 API 并缓存可用 IP；任务执行器调用接口时会自动从缓存中取号并在失效后回收。
4. 如需临时停用某个套餐，可使用“停用/启用”按钮切换状态，暂停后任务将不分配该服务商的代理。

## 3. 常见问题

| 问题 | 可能原因 | 建议措施 |
| --- | --- | --- |
| 任务提示账号失效 | Cookie 过期或风控 | 重新登录平台获取新 Cookie，并在资源列表中更新；必要时启用代理轮换。 |
| 仍返回 401/403 | 缺少关键字段 | 确认所有必需 Cookie 已按 `key=value` 格式拼接；小红书需带 `xsec_token`、`xsec_source`。 |
| 代理池刷新失败 | 凭证错误或套餐未启用 | 在快代理后台核对密钥与套餐状态，确认账号具备提取私密代理的权限。 |
| 频繁验证码 | 请求过快 | 降低 `CRAWLER_TIME_SLEEP` 配置，或增加账号/代理数量。 |

## 4. 安全与合规提示

- 所有账号与 Cookie 都是敏感数据，请通过环境变量或密钥管理服务进行托管，避免提交到代码仓库。
- 遵守目标平台服务条款，勿进行大规模批量抓取。
- 建议定期更新账号与代理资源，并启用审计日志追踪资源使用情况。
